# BiaxialShearStrainCuFeS2
Jupyter notebooks documenting Python-based workflows for running batch computations, validating outputs, and processing large model datasets. Focus on structure, reproducibility and automation of data analysis.

Contains data for the article “Shear Strain-Induced Multiferroic Response in the Altermagnetic Semiconductor CuFeS2”, https://arxiv.org/abs/2503.21637
